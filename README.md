C++ little neural network library that aims to run a llm on CPU (and possibly also to generate images).
Just to learn.

# Objectives
 - aproximate a function     X
 - mnist                     X
 - llm                       X

# How to use
### Clone the repo
```
git clone https://github.com/gjel64/LowNN.git
```

### Run the tests and the main
```
cd LowNN
mkdir build
cd build
cmake ..
make 
./run_test
./main
```
